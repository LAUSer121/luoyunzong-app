# 旧版功能对照表（luoyunzong.html → Flutter）

旧版是单文件网页（5,838 行：CSS 2,190 行 / 结构 680 行 / 脚本 2,960 行），
数据整体存于 `localStorage["luoyunzong_all"]`。下面是逐项迁移映射。

## 1. 数据模型（存档 `archiveVersion: 4`）

| 旧字段 | 类型 | 新模型 | 说明 |
| --- | --- | --- | --- |
| `adminPassword` | string | `Archive.adminPassword` | 默认 `123456`，仅控制编辑权限 |
| `memberList[]` | array | `List<Member>` | `name/role/mainRank/subRank/avatar/portrait/video/subRoles[]/contribution` |
| `towerList[]` | array | `List<TowerRecord>` | `name/role/mainRank/subRank/avatar/subRoles[]/passCount/isChampion` |
| `taskConditions` | object | `Map<TaskGrade, List<String>>` | 天/地/玄/黄 可接职务列表 |
| `task_tian/di/xuan/huang` | string | `Map<TaskGrade, String>` | 任务正文 |
| `notice` / `update` | string | `Archive.notice` / `Archive.updateText` | 公告与更新内容 |
| `bgm` | object | `BgmSetting` | `volume/customNames[]/index` |
| `bg` | object | `BackgroundSetting` | `type: default\|preset\|image`，`key`/`data`/`css` |
| `peakList[]` | array | `List<Peak>` | `name/avatar/leader/members[{name,contribution}]` |
| `motto` | string | `Archive.motto` | 默认「落云宗：聚天地灵气，养一方道心；同门同心，其利断金。」 |
| `examData` | object | `ExamData` | `threshold/thresholdExcellent/sessions[{id,name,time,records[{name,score}]}]/currentSession/compareA/compareB` |

旧档迁移：`examData.categories[].sessions[]`（含科目层级）与更老的
`categories[].records[]` 会被 `ArchiveCodec.migrateExamData()` 扁平化为全局 `sessions`。

## 2. 职务与境界

- 职务权重（决定名单排序，从高到低）：通天塔榜首 11 > 宗主 10 > 峰主 9 > 长老 8 >
  执事 7 > 第一天骄 6 > 第二天骄 5 > 天骄 4 > 核心弟子 3 > 内门弟子 2 > 外门弟子 1 > 凡人 0。
- 境界主阶：炼气 1 / 筑基 2 / 金丹 3 / 元婴 4 / 化神 5 / 炼虚 6；小阶：前期 1 / 中期 2 / 后期 3 / 大圆满 4。
  综合分 `realmScore = 主阶×10 + 小阶`（旧版 `realmScore()`）；凡人记 0 且显示「凡体」。
- 默认任务可接职务：天〔天骄/执事/长老/宗主〕、地〔+核心弟子〕、玄〔+内门弟子〕、黄〔+外门弟子〕。

## 3. 页面级功能

### 3.1 宗门名单
- 手动录入：头像（压缩到 256px / JPEG 0.85）、姓名、职务、主阶、小阶；凡人不设境界。
- 批量导入：每行「姓名 职务 境界」，分隔符为空格/中英文逗号/顿号/冒号/分号/竖线/制表符；
  职务缺省「外门弟子」、境界缺省「炼气前期」；同名跳过；凡人的境界自动置为凡体。
- 列表：位次（前三名金银铜高亮）、头像、姓名、职务徽章 + 兼任徽章（峰主·某峰、通天塔榜首）、
  境界徽章、贡献点、操作（修改/删除）。
- 编辑行内：改职务、改境界、改贡献点、设置兼任职务（多选）。
- 统计条：宗门总人数 / 弟子 / 天骄 / 执事 / 长老 / 宗主 / 凡人 / 山峰；境界分布（六阶）。
- 宗旨（motto）点击可改，空值回落默认。

### 3.2 人物立绘与动态视频
- 点头像打开详情弹窗：立绘（无立绘显示「侠」占位）、上传/移除立绘、上传/移除视频。
- 视频限制：≤ 20MB、时长 ≤ 25 秒；点击立绘切换到播放视频，播完回到立绘。
- 立绘/视频以 base64 存进存档，随导出导入迁移。

### 3.3 宗门任务
- 天/地/玄/黄四档折叠面板，各自一段富文本；「全部展开/全部收起」。
- 「可接职务」可多选修改，实时回写存档。

### 3.4 通天塔榜单
- 添加记录：输入姓名（必须存在于宗门名单）与已通关数量；记录保存当时的职务/境界快照。
- 排序：榜首固定第一，其余按通关数降序。
- 指定/取消榜首：同步给成员加/去「通天塔榜首」兼任徽章。
- 表格展示优先取宗门名单的实时职务/境界，成员离宗时回退到快照。

### 3.5 山峰
- 创建：峰名 + 峰头像（压缩 256px）+ 峰主（未入峰的成员，凡人不可为峰主），峰主自动成为首名成员。
- 每峰上限 7 人；一人只能归属一峰；峰内可招收、移除、改任峰主、手动记贡献点、解散。
- 山峰总贡献 = 成员贡献点之和。

### 3.6 宗门排行榜（自动生成，剔除宗主与长老）
- 通天塔榜（前三，按通关数；用成员当前职务判断是否剔除，离宗用快照）、
  修为榜（前三，按 realmScore）、贡献点榜（前三）、山峰榜（总贡献第一的峰与其峰主）。
- 不足三名时用「—」占位。

### 3.7 成绩导入
- 场次管理：新建（名称唯一，时间默认当前）、切换、删除；场次下拉标签形如
  `三月演武 03-15 10:00（28人）`。
- 文本导入：每行「姓名 成绩」，自动跳过表头行（姓名/名字/成绩/分数/得分/科目开头），
  未匹配宗门名单的姓名跳过并提示。
- 文件导入：CSV / TXT / XLSX（XLSX 支持自选姓名列与成绩列）。
- 分数线：达标线（默认 60）、优秀线（默认 85）；≥优秀=优秀，≥达标=达标，其余不达标。
- 本场成绩表：位次/头像/姓名/职务/境界/成绩（可改）/删除。
- 统计：参考人数、平均分、最高分、最低分、优秀/达标/不达标人数。
- 分数段：90-100 / 80-89 / 70-79 / 60-69 / 60以下，带百分比条形。
- 分数线名单：优秀 / 达标 / 不达标三组姓名。
- 山峰汇总（本场）：各峰参考人数、平均分、最高分，外加全宗合计行。
- 个人成绩追踪：折线（成绩实线 + 排名虚线，双 Y 轴）+ 明细表（场次/成绩/排名/时间）。
- 两场对比：并列成绩、差值（▲▼）、排名变化（↑↓）、缺考/新增状态。
- 导出本场 CSV（含 BOM，表头：场次,姓名,宗门职务,修为境界,成绩,排名,等级）。

### 3.8 公告 / 更新内容
- 各自一个大文本域，未解锁时只读。

### 3.9 外观与 BGM
- 背景：默认 / 5 套预设风格（青雾缭绕、晚霞鎏金、紫气东来、翠微青山、星辰夜幕）/ 本地图片（压缩 1920px）。
- BGM：悬浮播放器（播放/暂停、上一首/下一首、音量、曲单弹窗）；
  曲单支持「同目录文件名」（随存档保存）与「本次打开的本地文件」（临时）。

### 3.10 存档
- 保存 / 读取本地存档；导出 `落云宗存档.js`（`window.__LUOYUN_SAVE__ = {...}`）/ `.json`；
  导入时密码随存档更新；清空全部。
- 旧版自动导入：同目录 JS → JSON → localStorage 三级回退。新版改为：启动即读本地存档，
  首次可用「导入旧存档」一次性迁移。

## 4. 权限模型

- 默认「只读模式」，输入管理员密码解锁编辑；解锁后才可写数据、导出、清空。
- 修改密码需校验旧密码，长度 ≥ 4，两次输入一致。

## 5. 已知旧版问题（新版已修正）

| 旧版行为 | 新版处理 |
| --- | --- |
| `localStorage` 容量上限导致立绘多时保存失败 | 存档落盘为文件（Web 仍受浏览器配额限制，会给出提示） |
| `window.__LUOYUN_SAVE__` 轮询等待 16 秒 | 启动直接读存档文件，无轮询 |
| 首页表格用 `innerHTML` 拼接，姓名含引号会破坏按钮 | Flutter 组件树渲染，无字符串拼接注入 |
| 视频/立绘 base64 全量常驻内存 | 按需解码并缓存，列表只渲染缩略图 |
| 编辑态用全局 `currentEditIndex` 跨表冲突 | 编辑态收敛到页面局部状态 |
